# Restorey v0.1 engine — rulings

Every decision made while building the v0.1 engine ([plan](superpowers/plans/2026-11-10-v0.1-engine.md)),
copied from the plan's working ledger when the branch merged on 12 Nov 2026. Each reads: what was decided — why — what
it costs if wrong. Commit messages and code comments cite them by number. Results of the live checks are in
[v0.1-measurements.md](v0.1-measurements.md).

- Ruling R55 (owner chose 'agent stops after current step'; text from docs/spike-findings.md): the helper's requirement is unchanged.
