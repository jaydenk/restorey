## Global Constraints

- Root causes, not patches. TDD: a failing test first for every behaviour change; app-only AppKit changes that have no
  test seam are verified by building and by eye, and say so in the report.
- Docs (README, specs) updated in the same commit as the behaviour they describe. Australian English.
- Never run restic against the owner's B2 repository. Never read the Keychain or
  `~/Library/Application Support/com.jaydenkerr.restorey*` (logs and state are read-only, and only when a task says).
- No CPU-load or repeated test loops on this Mac. Per task: the filtered tests plus the package suite it touches;
  `scripts/ci.sh` once at the end of the branch.
- Agent status paths stay disk-free (`StatusPathPurityTests`).
- Commits: no Co-Authored-By or session lines.

## Review Focus

1. A backup with tens of thousands of unreadable items (a whole unreadable volume): memory stays bounded and the
   "N files couldn't be read" count stays right.
2. The first backup of a plan (no previous backup to compare): the forget-skip rule never fires.
3. Paths that differ only by the `/private` firmlink (`/tmp`, `/var`, `/etc`) compare equal in every place the two
   follow-ups touch, and paths that merely start with the same letters don't (`/private/tmpx` vs `/tmp`).
4. A folder on a network volume that stops answering, dropped on the Folders list: the window keeps responding and
   the folder is refused or accepted within the deadline.
5. An unsigned Debug build talking to its agent after the code-signing requirement lands: dev builds still connect
   (the requirement is only enforced where both sides are signed by the team).

Each has a test (or, for 5, a stated build check) in its task.
